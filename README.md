## What I Work On

I like building things that make complicated ideas easier to see, manipulate, and understand.

- **Creative software** — presentation tools, vector editors, interactive canvases, animation systems, and UI experiments.
- **Scientific tooling** — chemistry workflows, crystallization logic, visual explainers, and data-oriented experiments.
- **Design systems** — sharp interfaces, iconography, vector illustration, branding, and layout-heavy web experiences.
- **Engineering experiments** — browser graphics, SVG/PDF/PPTX conversion, geometry engines, performance work, and automation.

---

## Current Focus

I’m currently focused on building advanced browser-native creative tooling — especially systems that combine:

- vector design
- motion/keyframe animation
- math + LaTeX rendering
- interactive graphs
- chemistry diagrams
- semantic document conversion
- high-fidelity presentation workflows

The long-term goal: software that feels as flexible as a design tool, as expressive as an animation tool, and as precise as a scientific instrument.
